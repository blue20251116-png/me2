# Threads 영상 소재 탐색 방향

샤오홍슈 기반 소재 탐색은 사용하지 않는다.
앞으로 제품/레시피 영상 소재는 Threads 공개 게시물의 인기·관련 영상 탐색을 1순위로 검토한다.

## 핵심 목표

상품 또는 레시피 주제를 기준으로 Threads에서 관련 공개 게시물을 찾고,
그중 짧은 영상이 포함된 게시물을 소재 후보로 보여준다.
최종 게시용 글은 원문을 복사하지 않고 me2의 자체 AI 프롬프트로 새로 생성한다.

## 레시피 모드

1. 레시피 주제 자동 선정
2. Threads에서 요리명 중심으로 관련 게시물 탐색
   - 예: 김치볶음밥
   - 김치볶음밥 레시피
   - 간단 김치볶음밥
   - 자취요리 김치볶음밥
3. 영상 포함 게시물 우선
4. 가능하면 반응이 좋은 게시물 우선
5. AI/Vision으로 실제 목표 음식과 일치하는지 확인
6. 조리 과정 또는 완성 음식이 잘 보이는 영상 우선
7. 짧은 영상 우선
8. 사용자가 최종 소재 선택
9. 선택된 사용 가능 영상은 기존 영상 파이프라인으로 전달
   - 음소거
   - 시작/끝 컷
   - 대표 프레임 추출
10. 게시 구성
   - 짧은 영상
   - 영상 속 메인사진 1장
   - 사람 말투의 새 레시피 본문
   - 댓글에 재료/계량/조리순서/제휴 링크

Threads 영상 소재가 없거나 사용할 수 없으면 기존 Pexels/Pixabay 음식 이미지 검색을 fallback으로 사용할 수 있다.

## 일반 상품 모드

1. 상품 선택
2. 식품/신선식품/영양제 등은 일반 상품 영상 탐색에서 제외하고 레시피 또는 별도 콘텐츠 루트로 보낸다.
3. 생활용품, 주방용품, 자동차용품, 운동기구, 수납/정리, 소형가전 등 영상 시연 가치가 높은 상품을 우선한다.
4. Threads에서 상품명/핵심 기능 관련 공개 영상 게시물 탐색
5. 영상 포함 게시물 우선
6. 제품과 실제 영상 속 물건의 유사도를 확인
7. 짧고 기능이 바로 보이는 영상을 우선
8. 사용자가 최종 소재 선택
9. 기존 영상 파이프라인으로 전달
   - 음소거
   - 앞뒤 컷
   - 대표 프레임 추출
10. 게시 구성
   - 짧은 영상 1개
   - 대표 이미지 1장
   - 사람 말투 본문
   - 일반 상품용 제휴 댓글

## 짧은 영상 우선 기준

영상 후보 점수 계산 시 아래 조건에 가산점을 준다.

- 5~20초 정도의 짧은 영상
- 처음 몇 초 안에 상품/음식이 바로 보임
- 제품 사용법이나 변화가 한눈에 이해됨
- 레시피는 조리 장면 또는 완성 음식이 명확함
- 세로형 또는 모바일 피드에서 보기 좋은 영상
- 자막/로고가 화면을 과도하게 가리지 않음

## 글 생성 규칙

영상 소재를 찾았더라도 원 Threads 게시물의 문장이나 캡션을 그대로 복사하지 않는다.

본문은 me2의 현재 사람 말투 프롬프트를 사용한다.

- 설명보다 상황/썰 먼저
- 광고 카피처럼 기능 나열 금지
- 최근 게시물과 후킹 표현 중복 최소화
- 음슴체 금지
- 허위 사용 경험/효능/수치 금지

레시피 본문과 일반 상품 본문은 서로 다른 프롬프트를 사용한다.
댓글도 레시피 댓글과 일반 상품 댓글을 반드시 분리한다.

## 권장 UI

`Threads 소재 찾기` 영역을 별도로 둔다.

후보 카드 예시:

- 영상 미리보기
- 게시물 요약
- 확인 가능한 반응 지표
- 영상 길이
- 상품/요리 관련도 점수
- 원문 보기
- 이 소재 선택

1차 버전에서는 AI가 자동으로 최종 영상을 결정하지 않고 후보를 보여준 뒤 사용자가 선택하는 반자동 방식을 우선한다.

## 현재 유지할 영상 기능

- 내 영상 직접 업로드
- FFmpeg 영상 프레임 추출
- AI 베스트컷 추천
- 영상 음소거
- 시작/끝 컷

샤오홍슈 다운로드/검색 기능은 제거한다.
